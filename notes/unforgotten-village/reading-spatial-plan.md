# 『忘れ物のない村』空間朗読・試聴メモ（v0）

## 位置づけ
本作は壁ラジEpisodeではなく、短編小説の独立した朗読試作。YouTubeへの公開・動画作成は**未決定**。まずヘッドホンで音響を評価する。

- 原作：[article.md](article.md)
- 朗読台本：[reading-spatial.md](reading-spatial.md)
- 音響試聴用抜粋：[reading-spatial-preview.md](reading-spatial-preview.md)
- 実行環境：[Spatial Audio Studio](https://github.com/amakawa-chan/amakawachan-assistant/blob/main/Radio/spatial/STUDIO.md)（Amakawachan Assistant本体のmainにも配置済み）
- 音声：**モブ美ひとりで全役を朗読**する。既存のモブ美Voiceだけを利用し、原作の文言は改変しない。

## 今回の役割と定位

| 役割 | Studio上の話者 | 定位 | メモ |
|---|---|---|---|
| 地の文・主人公 | モブ美 | 中央、pan 0 | ずっと正面。叙述の声も会話の声も同一 |
| 喫茶店の老人 | モブ美 | 右、pan +0.62 | 少し近め、small_room |
| 赤い自転車の少年 | モブ美 | 左、pan -0.63 | 屋外らしくdry |
| 広場の女性 | モブ美 | 右、pan +0.48 | 軽く遠ざけ、柔らかく |
| 役場の老人 | モブ美 | 左、pan -0.58 | small_room。落ち着いた距離 |
| AI通知 | モブ美 | 中央、pan 0 | phoneフィルターで村人と質感を分ける |

**狙い：** あえて複数Voiceを使わず、**同じモブ美の声が場面ごとに中央・左右へ移る**演出を試す。聴き手が台詞の前後関係・パン・距離だけで人物を追えるかを検証する。Studioが元々対応するモブ美Voiceと発話単位の音響設定だけで実施できる。

**語り・主人公は中央固定**：モブ美Voiceの地の文と主人公の台詞はpan 0。モブ美Voiceの村人台詞だけ左右へ振る。過度の耳元±0.98はまず使わない。左右方向だけでは人物判別が難しい可能性があるため、場面転換の間や距離で補う。

## 試聴の順序

1. 冒頭の「忘れ物のない村」で中央の声質・話速・間を聴く。
2. 「砂糖二杯」で右側の老人と中央の主人公の掛け合いを聴く。
3. 「赤い自転車と長椅子」で左の少年から右の女性へ場面が移る感覚を確認。
4. 「二十一人の村」で老人の左定位を確認し、違和感がうるさくならないか評価。
5. 「記録しない一日」でAI通知の帯域処理を聴く。「住民二十二名」のあとの余韻を確認。

## 現状の起動・使用

1. WindowsのKawaii Launcherから **Spatial Audio Studio** を起動。
2. 「台本を開く」で`reading-spatial.md`のローカルコピーを開く（KabeRadioの原作とは別ファイル）。
3. モブ美の語り・主人公台詞は中央、同じモブ美の村人台詞だけ左右に設定した状態で試聴。GUIで微調整可能。
4. 「全編WAVを書き出す」で試聴版を作成。出力とTTSキャッシュはRadio側の`Radio/runs/spatial-studio/`に保存され、Git管理外。

## 現状のStudioで注意する点

- 台本を開いて試聴・WAV化は可能だが、GUIで原文テキスト自体や話者追加はできない。
- 話者の声色を場面ごとに変える機能、BGM/環境SEの多層ミキシング、全編の途中シーク、生成中キャンセルは未対応。
- 長尺（この原作のような数百発話）のレンダリング実機試験は未確認。最初は各章の数発話を試聴し、最後に全編出力を試す。
- 現行レンダラーは通常の地の文を読み上げない。台本化にあたり、原作の各段落を **話者**＋「読み上げ文字列」に変換している。
- 読み上げに適したルビや読みの正規化（`珈琲`、`住民二十二名`など）は試聴して必要があれば派生台本だけで直す。原作の`article.md`は変更しない。
- 新しい舞台演出やYouTube版の尺・背景・字幕は初回WAVの試聴後に決める。

## 初回テストで次に判断すること

- **モブ美ひとりの読み**で、村人の会話が追えるか？ → パンと間だけで分からない場合は、将来の軽い演出追加を検討。複数話者導入は必須としない。
- 話者が切り替わる箇所の定位差が強すぎないか？ → pan/gain/roomを一括で見直す機能の必要性を判断。
- 朗読向けに「章頭の長い間」「台詞の前後の短い間」「地の文のテンポ」を調整できるか？
- 全編WAVのレンダリングが長尺で安定するか？

このテストは次の大型開発を約束するものではなく、**いまあるStudioの再利用で一本聴けるか**を見極めるための試作。
