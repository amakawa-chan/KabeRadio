# 制作ノート

壁ラジ本編の文字起こしではなく、壁打ちから何を考えてどこへ話が転がったかを残す制作記です。

GitHub PagesをRepository rootから公開している場合、以下の公開ページをiPhone / Safariからそのまま閲覧できます。

- [本編が一番過疎なので、壁ラジを深夜ラジオへ戻すことにした](https://amakawa-chan.github.io/KabeRadio/notes/late-night-radio-reframe/)
- [シャワーの最後だけ固定してしまえばいい](https://amakawa-chan.github.io/KabeRadio/notes/shower-cooldown-routine/)

各公開ページには「本文をコピー」ボタンがあり、noteへの貼り付け用にも使えます。


## Note Card Generator

noteへ投稿するタイミングで、制作ノートのキャラクター引用をPNGカードへ変換できます。

- [Note Card Generatorを開く](https://amakawa-chan.github.io/KabeRadio/notes/tools/note-card-generator/)

`article.md` を貼り付けるか読み込み、モブ子・モブ美・あまかわちゃんのblockquoteを抽出します。
単発コメントと短いミニ会話に対応し、PNG保存または対応ブラウザでは画像コピーができます。
