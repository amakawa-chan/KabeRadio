# AIに開発プロジェクトを監査させたら、ワンマン社長だった

## Episode Description

デスクトップにモブ子を置いて喋らせたい、から始まった開発。GitHubの関連14リポジトリをAIに評価させたら、開発スピードは高評価なのに、実機確認の報告漏れとワンマン社長疑惑が浮上。今回はモブ子が長めに喋る監査回です。

そうね。開発が楽しいのもあるけど、すぐ試せるのが楽しいんよ。
