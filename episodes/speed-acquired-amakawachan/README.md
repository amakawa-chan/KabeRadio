# 速さを手に入れたあまかわちゃん

声が舌ったらずに感じていた原因は、Character Packの話速がRadioの合成に渡っていなかったこと。1.2倍になったあまかわちゃんがモブ子にしつこく変化を尋ね、なぜか3倍の速さを主張する短編メタネタ回。

- Host: `amakawachan-layered`
- Guest: `mobuko-v2`
- [Canonical Script](script.md)
- Shorts候補: 6件（生成対象は未選択。試聴後に4件程度へ絞ることを想定）

## 制作時の確認

Radioを再起動し、Host側の話速1.2とGuest側の話速1.0が実際の本編に反映されることを聴感確認する。生成済み音声の再使用ではなく、新しく音声を生成して試聴する。実機確認前に成功済みと断定しない。

短編のため、通常15分尺への水増しを行わない。思慮時間は元ログの時刻が不明なため記載しない。
