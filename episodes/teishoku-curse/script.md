# 定食の呪い

## Episode Description

外食ならパスタ一皿で満足するのに、家の夕飯だともう一品ほしくなる。鶏肉とキノコの炊き込みご飯に卵焼きと冷奴を足した日から、食卓の理想と手間の折り合いを考え始めた。
