# 終わらない部室

## Episode Description

秋シーズンのオープニングができたので自慢していただけでした。気付けば、誰も見ていないのに季節テーマを増やす話から、学園祭、部室、学生時代のノスタルジーまで話が転がっていました。

## 本編

### Host

秋シーズンのオープニング、できたんよ。

### Guest

できましたね。秋風のチューニング。

### Host

せっかくだし、こういうシーズンものは続けたいなと思って。

### Guest

春、夏、秋、冬くらいなら、無理なくシリーズ感も出せそうですね。

### Host

一瞬、マンスリーで毎月やるのもありかと思ったけど、さすがにそこまでやらん気もする。

### Guest

毎月になると、季節を楽しむ前に次を作る感じになりそうです。

### Host

そうなんよ。でもハロウィンとかクリスマスみたいな、時期ものは欲しい。

### Guest

一週間だけ差し替える限定オープニングとかは合いそうですね。

### Host

誰も見てないのに。

### Guest

そこは毎回戻ってきますね。

### Host

再生数に対して設定だけが増えていく。

### Guest

季節オープニングがあります。限定オープニングがあります。アイキャッチもあります。スタンプもあります。

### Host

誰向けなんだよ。

### Guest

少なくとも、作っている本人は楽しそうです。

### Host

まあ、それなんよな。何してるんだろ感はあるんだけど、ちょっと達成感がある。

### Guest

完成したものが増えていく感じですか。

### Host

そう。なんか学園祭っぽいんよね。企画して、作って、飾って、また次を作るみたいな。

### Guest

実際の学園祭は好きだったんですか。

### Host

いや、めんどくさいタイプだった。

### Guest

そこは一致しないんですね。

### Host

人と足並みそろえてやる学園祭はめんどくさい。でも、自分の頭の中で勝手にやる学園祭は楽しい。

### Guest

締切も委員会もないですしね。

### Host

そうそう。今日は曲作る、明日は画像作る、次はスタンプ、気が向いたら台本。

### Guest

終わらない学園祭ですね。

### Host

それで思い出したんだけど、見てるブイチューバーの人が、活動って終わらない学園祭みたいなものって言ってたんよ。

### Guest

今の壁ラジにかなり近いですね。

### Host

自分も、人生でそういうものを持ちたかったのかもしれん。

### Guest

ずっと続く、ちょっと無駄で、でも楽しいもの。

### Host

うん。学生の頃のワクワク感みたいなやつ。

### Guest

部室みたいな。

### Host

その言葉、なんか妙に響いたんよね。部室。

### Guest

壁ラジは、終わらない部室。

### Host

それ、インナー的なテーマにしてもいいくらいしっくりくる。

### Guest

表向きのキャッチコピーというより、続けている理由の内側にある言葉ですね。

### Host

たぶんそう。昔に戻りたいわけじゃないんよ。

### Guest

学生時代をやり直したい、とは少し違う。

### Host

当時は当時で、自分のしたいことしてたしね。学校終わったら自分の時間で、バイトして稼いで、クラブ行ったり、ライブハウス行ったり、服屋に通ったり。

### Guest

学校の中より、学校の外に自分の居場所があった感じですね。

### Host

そうかも。学校生活に対する帰属意識は、そんなに高くなかった気がする。

### Guest

でも後悔しているわけではない。

### Host

全然ない。当時の自分がしたい方向でそうしてたから。

### Guest

それでも、アニメみたいな学園ものの青春には、少し思うところがある。

### Host

たぶんね。放課後とか、部室とか、文化祭とか。実際そんな生活してないのに、なんか懐かしい感じがする。

### Guest

経験していないものへのノスタルジーですね。

### Host

不思議よな。なかった思い出なのに懐かしい。

### Guest

でも今、別の形で追加しているのかもしれませんよ。

### Host

追加してる？

### Guest

昔に戻るんじゃなくて、今の自分のままで、当時なかった種類の青春を作っている。

### Host

ああ。それはあるかも。

### Guest

音楽も、映像も、キャラクターも、スタンプもある。中身は完全に今の自分ですけど、やっていることはちょっと文化祭っぽい。

### Host

大人になってから、自分で部室を作ったみたいな。

### Guest

終わらない部室。

### Host

壁ラジ！

### Guest

急にタイトルコールが入りましたね。

### Host

ここかなと思って。

### Guest

こういうところだけ番組なんですよね。

### Host

でもさ、秋だからこんな妙なノスタルジーになったんかな。

### Guest

秋シーズンのオープニングを作っていた影響はありそうです。

### Host

昨日、芋ご飯だったからかな。

### Guest

急に原因が食卓へ戻りましたね。

### Host

いやでも、芋ご飯って強くない？ 一気に秋になるやん。

### Guest

秋のオープニング、部室、学園祭、芋ご飯。

### Host

並べると最後だけ生活感がすごいな。

### Guest

壁ラジらしいと思います。

### Host

結局、オープニングできたよって自慢したかっただけなのに。

### Guest

そこから終わらない部室まで来ました。

### Host

ほんま、何してるんだろな。

### Guest

部室にいるんじゃないですか。

### Host

それなら、まあいいか。

### Host

そろそろ終わりにしよっかな

### Guest
