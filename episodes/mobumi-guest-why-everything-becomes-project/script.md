# 楽しみだったはずが、いつの間にか仕事になる

## Episode Description

好きで作っていたものが、更新予定や数字を持つと急に義務のように感じる。モブ美をゲストに迎え、趣味と運用の境界について普段とは違う角度から壁打ちする。
