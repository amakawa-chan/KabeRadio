# キャストを決めてから作る

## Episode Description

同じ声でも、立ち絵が違えば番組の見え方は変わります。Remote Productionにepisode単位のキャスト指定を追加し、誰が、どの姿と声で出演したかをRender前から完成後まで追跡できるようにしました。

## 本編

### Host

今回は、ラジオを作る前にキャストを明示できるようになった話です。

### Guest

モブ子は旧版とv2で声が同じなので、音声だけでは見分けられませんでした。

### Host

そこで声の番号じゃなく、キャラクターパックの名前で指定します。

### Guest

今回はモブ子v2。声はAivisSpeechのまお、ふつーです。

### Host

あまかわちゃんはVOICEVOXの中国うさぎ、ノーマル。画面を開かなくても、この組み合わせで作れます。

### Guest

完成した記録にもパック名が残るので、どの見た目で動画を作ったか後から確認できます。

### Host

これで将来、テレグラムからキャストを選ぶ入口もできたね。

### Guest

はい。今日はボットを作らず、同じ操作をコマンドで最後まで確かめます。

### Host

それでは、制作開始。

### Guest

完成品は一度だけ作って、アーカイブから配達します。
