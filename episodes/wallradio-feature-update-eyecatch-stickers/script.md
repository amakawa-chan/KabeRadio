# 壁ラジ、また機能が増えました

## Episode Description

アイキャッチを付けたという話をしていたら、その横で壁ラジのLINEスタンプ第1弾と第2弾も審査中になっていました。誰も急がせていないのに、番組の外側だけが着実に育っています。

## 本編

### Host

今回は、壁ラジの機能追加報告会です。

### Guest

会議なんですか。

### Host

会議というほどではない。最近また機能が増えたので、一回ちゃんと報告しておこうかなと。

### Guest

一回ちゃんと、ということは、今までちゃんと報告してなかったんですね。

### Host

実装して満足して、そのまま次へ行くことが多いからね。

### Guest

知っています。

### Host

まず、アイキャッチが入りました。

### Guest

入りましたね。今まで台本の途中で普通に読んでいたタイトルコールを、完成した動画と音声へ置き換えられます。

### Host

そこ、ちょっと番組っぽくなったよね。

### Guest

前から番組ではあったはずなんですけど。

### Host

台本の書き方は変えなくていいんよね。

### Guest

はい。台本には今までどおり、独立したタイトルコールを一回だけ書きます。どのアイキャッチを使うかは、ラジオアプリ側で決めます。

### Host

種類を指定するか、ランダムにするか選べる。

### Guest

六種類から選べます。ランダムでも、ポッドキャストを作る時に一度だけ確定して、動画にも同じものを使います。

### Host

動画にしたら別のアイキャッチへ変わってた、みたいにはならない。

### Guest

なりません。何を使ったかも成果物に残ります。

### Host

思ったより厳密やな。

### Guest

タイトルコール一言を派手にするための仕組みとしては、かなり真面目です。

### Host

しかも元の台本は、そのまま残る。

### Guest

はい。通常の読み上げとアイキャッチ内の声が二重に鳴ることもありません。アイキャッチの間は本編の音を抑えて、終わったら戻ります。

### Host

一言を差し替えるだけなのに、ちゃんと制作機能になってるな。

### Guest

作った本人が、今それを確認しているんですか。

### Host

機能追加報告会なので。

### Guest

便利な言葉ですね。

### Host

壁ラジ！

### Guest

今の一言が、出力するとアイキャッチになるわけですね。

### Host

説明してから実演する番組。

### Guest

急に機能紹介動画みたいになりました。

### Host

で、もう一個報告があります。

### Guest

まだ増えたんですか。

### Host

壁ラジのラインスタンプ、第1弾と第2弾が審査中です。

### Guest

第1弾と、第2弾。

### Host

はい。両方。

### Guest

第1弾が通る前に、第2弾も出したんですか。

### Host

出しました。

### Guest

前にも同じような流れを見た気がします。

### Host

前のモブ子スタンプとは別で、今度は壁ラジのスタンプです。

### Guest

私のスタンプを作った後、番組そのものまでスタンプになったんですね。

### Host

アイキャッチが増えて、スタンプも二つ審査中。

### Guest

番組の中身より、番組の周りが先に充実していませんか。

### Host

再生数より周辺展開が先に増えていく。

### Guest

普通は順番が逆な気もします。

### Host

でも、誰も聴いてないうちに全部揃えておけば、いつ聴かれても困らんよ。

### Guest

準備だけは万全ですね。

### Host

アイキャッチが流れて、スタンプがあって、ラジオも二十四時間動かせる。

### Guest

あとは聴く人ですね。

### Host

一番最後に実装されるやつ。

### Guest

それは実装できません。

### Host

そろそろ終わりにしよっかな

### Guest

お疲れ様でした

### Host

後でまとめておいて

### Guest

できる範囲で

### Host

それではまたどこかで

### Guest

またどこかで
