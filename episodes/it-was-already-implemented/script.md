# 未来の話をしたら、だいたいもう実装されてた

## Episode Description

新しく機能が増えたAmakawachan Assistantを見ながら、この先どんな常駐キャラクターになっていくのかを話していたはずでした。ところがGitHubを確認すると、未来予想として挙げた機能の大半が、すでに現在のシステムに入っていました。
