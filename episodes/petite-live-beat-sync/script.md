# 終わるはずだったのに、ミニキャラをBPM同期したくなった

## Episode Description

ひとしきり思いついた機能を実装し終えて、一度ここで区切ろうとしていたところから始まった壁打ち。ところが、ぷちライブのミニキャラを音楽のビーピーエムに合わせて踊らせたい、という忘れていた案が急に戻ってきます。
