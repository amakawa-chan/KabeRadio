# 終わるはずだったのに、ミニキャラをBPM同期したくなった

ひとしきり思いついた機能を実装し終えて、一度ここで区切ろうとしていたところから始まった壁打ちです。ぷちライブのミニキャラを、再生中の音楽のBPMに合わせて自然に踊らせたい、という「最後にもう一個」が発覚します。

- Host: `amakawachan-layered`
- Guest: `mobuko-v2`
- Script: [script.md](script.md)

## 検証目的

ぷちライブのBeat Sync Mode構想を、機能範囲を広げすぎずに整理する短編です。Windowsの再生音からBPMを自動推定してモーション速度を追従させ、音楽停止や推定不能時は通常速度へ戻す、というところまでを今回の停止線として扱います。
