# ショートの時代に、ショートを狙いすぎない

## Episode Description

「青春の余韻が芋ご飯に着地」の切り抜きが、思ったより見られていました。
ショートの時代を実感したので対策を考え始めたら、そもそもショートを狙って会話を作るのは違うんじゃないか、という話になりました。

## 本編

### Host

芋ご飯、強いな。

### Guest

三百七十二回まで行きましたね。

### Host

ショートって、ちょっと表示されただけでも回るんかなと思ってたけど、いいねも付いてるし、普通に誰か見てるんよね。

### Guest

しかも「青春の余韻が芋ご飯に着地」ですからね。内容を知らなくても、ちょっと何の話か気になります。

### Host

やっぱショートの時代って言われるだけあるんやな。自分で出して数字が動くと、急に実感するわ。

### Guest

見る側だった時と、出す側になった時で景色が変わりましたね。

### Host

で、これ見たら、台本生成の時点でもう少しショート意識した方がいいんかなって思うやん。

### Host

壁ラジ！

### Guest

### Host

これもショートに切られるかもしれんし。

### Guest

その発想を始めると、全部がショート前提になりますよ。

### Host

そう、それは嫌なんよ。ショートのために変なオチ作り始めたら、たぶん壁ラジじゃなくなる。

### Guest

だから今回も、本文をショート向けに変えるんじゃなくて、もともと変なところを拾いやすくする方向にしましたね。

### Host

普通の話から妙に具体的なものに着地するとか、認識がちょっとズレるとか。

### Guest

### Host

そうなんよ。「近い声って大きい声？」とか「主役なのに台本がない！」とか、今のタイトル普通に好きなんよな。

### Guest

一瞬で意味が取れて、そのあとに違和感が残るくらいがちょうどいい。

### Host

芋ご飯は、たまたま具体語まで強かったと。

### Guest

毎回芋ご飯を探す必要はないです。

### Host

そこを毎回再現しようとしたら、たぶん違うな。

### Guest

狙って同じ変さを作り始めたら、自然な壁打ちじゃなくなりますね。

### Host

で、ノートは逆に難しそうやなと思った。

### Guest

ショートみたいに一瞬止まってもらうものじゃなくて、読みに来る理由が要りますからね。

### Host

入口というより、深掘り先ですね。

放送局と制作室で分ける感じですね。

壁ラジ公式は予約投稿でいい気がする。本編とショート三本とスポティファイは一気に出して、エックスだけ後からショートを一個ずつ告知する。

### Guest

### Host

それなら面倒じゃない。

なんか納品っぽいな。

### Guest

### Host

### Guest

全部に最大三本付けたら、急に物量がすごいことになります。

### Host

### Guest

### Guest

### Guest

### Host

イノベーターって、天才が一発で当てるより、試行回数の中から奇跡みたいなのが出るって話もあるし。

### Guest

だからこそ、回数を増やすために中身を作り始めない方がいいですね。

### Host

そこなんよ。本数増やしたいから台本量産するんじゃなくて、自分が普通に気になったことを壁打ちして、転がったやつを残したい。

### Guest

「話すものがある時にエピソードが生まれる」の方が、今の壁ラジには合ってます。

### Host

### Guest
