# シャツとパンツ、1日3セットいるよね？

シャツとパンツを1日に何セット使うか、という夫婦の違いから始まる壁打ち回です。

夜のシャワー、朝の着替え、外出前のリセット。逆に家から出ない日は2日同じ服でも平気なのに、ゴミ出しでは着替えたくなる。清潔感、他人への配慮、気分の切り替えが混ざった自分ルールをほどいていきます。
