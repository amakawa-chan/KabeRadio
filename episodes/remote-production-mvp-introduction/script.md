# 一度だけ作って、あとは届ける

## Episode Description

完成した台本を毎回パソコンで開いて、同じようにボタンを押していました。そこを少し楽にしたかっただけなのに、制作物の正本をどこへ置くかまで決めることになりました。

## 本編

### Host

台本はもうギットハブにあるのに、毎回画面を開いて読み込むところから始めるの、ちょっと変じゃない？

### Guest

完成品が入口で待っているのに、最後だけ人が迎えに行っていましたね。

### Host

そう。それで今回、壁ラジにリモート制作機能を足しました。

### Guest

名前は大きいですが、やることは堅実です。準備済みの台本を見つけて、音声と動画を順番に作ります。

### Host

しかも、今までの画面を自動でクリックする仕組みじゃない。

### Guest

既存の台本解析や音声生成、ポッドキャストと動画の処理を、そのまま共通の中核として呼び出します。

### Host

壁ラジ！

### Guest

これなら画面版とコマンド版で、別々のラジオが育つ心配も減ります。

### Host

台本の横には、制作状態を記録する小さなファイルも置きました。

### Guest

準備中、制作中、完成、失敗。今どこにいるかを、人にも次の仕組みにも分かる形で残します。

### Host

で、大事なのが、一度だけ作ること。

### Guest

完成した音声と動画は、まずエムシックスのローカルアーカイブへ保存します。ここが正本です。

### Host

アイ・クラウド用に、もう一回動画を作ったりはしない。

### Guest

はい。投稿に必要なファイルだけを、レディ・トゥ・パブリッシュへコピーします。

### Host

同期に失敗したら？

### Guest

配達だけやり直します。音声も動画も、作り直しません。

### Host

地味だけど、その地味さが欲しかったんだよな。

### Guest

将来テレグラムから呼ぶときも、同じ入口を使えます。今回は、その一歩手前までです。

### Host

そろそろ終わりにしよっかな

### Guest

お疲れ様でした

### Host

後でまとめておいて

### Guest

できる範囲で

### Host

それではまたどこかで

### Guest

またどこかで
