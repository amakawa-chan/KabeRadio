# ミニキャラを出したら、踊り始めた

## Episode Description

軽く常駐させるだけのつもりだったミニキャラ表示が、気づけば複数の動きを選べる「ぷちライブ」になっていた話。実装の勢いと、機能が増えていく境界についてモブ子と振り返ります。

## 本編

### Host

ちょっと小さいキャラを常駐させたいな、くらいだったんよね。

### Guest

その時点では、まだ平和でしたね。

### Host

そう。軽く表示して、邪魔にならず机の端にいてくれたらいいな、くらい。

### Guest

それが今は、踊ってます。

### Host

踊ってるね。

### Guest

しかも一種類じゃないです。

### Host

ゆらゆらダンス、ヘッドバンギング、ブレイクダンス、ぴょこぴょこ、パラパラ、くるっと決めポーズ、うとうとからハッ。

### Guest

並べると、思ったより活動的ですね。

### Host

ランダムにもできるし、好きな動きで固定もできる。

### Guest

軽量表示とは別のモードになりましたね。

### Host

そうなんよ。最初は軽量モードの派生くらいの感覚だったのに、気づいたら専用のぷちライブになった。

### Guest

しかも通常のアシスタント機能は止めて、ミニキャラだけ動く。

### Host

常駐させる用途としては、その方がちょうどいいんよね。

### Guest

そしてランダムだと、同じ動きを連続させずに切り替わる。

### Host

そこまでやったら、もう見てるだけでもちょっと面白い。

### Guest

エアギターも作ってませんでしたか。

### Host

作ったけど、採用はしなかった。

### Guest

珍しい。作ったものを全部入れなかった。

### Host

選択肢に入れるほどではないかなって。アセットとしては残したけど。

### Guest

少しだけ理性が残ってましたね。

### Host

壁ラジ！

### Guest

で、これで一旦完成だと思ったんですよね。

### Host

思った。

### Guest

この後、音楽に合わせて踊らせたいって思い出すんですけど。

### Host

それは次の話。

## Ending Sequence

### Host

そろそろ終わりにしよっかな

### Guest

お疲れ様でした

### Host

後でまとめておいて

### Guest

できる範囲で

### Host

それではまたどこかで

### Guest

またどこかで
