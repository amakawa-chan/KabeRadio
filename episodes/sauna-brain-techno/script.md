# サウナで脳内にテクノを流している話

## Episode Description

チープカシオの秒針で脈を測る話から、サウナで心拍をキックにして脳内でテクノを作る話に。外気浴で環境音に意識を預けるまで、考えすぎる頭の休ませ方を話した。
