# 自分のキャラクターがスタンプになった

## Episode Description

モブ子のグッズを作りたい、LINEスタンプも欲しい。そんな軽い思いつきから、コーデックスに制作を任せて32種類を作り、気付けば審査へ出していました。そして本当に承認され、最初の購入者まで決まりました。
