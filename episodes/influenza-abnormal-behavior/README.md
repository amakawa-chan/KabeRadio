# インフルの異常行動って、どこから異常？

家族内を順番に回ったインフルエンザのアンカーが自分っぽい、というところから始まる壁打ち回です。

子どもの発熱中に「いつも質問ばかりなのに急に喋らなくなった」「夜中に起きて歩いた」という普段との違いを振り返り、抗インフルエンザ薬の服用有無にかかわらず注意されている異常行動を整理します。

後半は自分の剃髪欲、歯を全部抜きたくなる極端な発想、高熱時にピアスを開けた昔話、そして晩ごはん後のそば150グラムから、どこまでが異常行動でどこからがただの食欲なのかを壁打ちします。
