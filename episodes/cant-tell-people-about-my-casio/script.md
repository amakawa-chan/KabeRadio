# 人に聞かせられない、私のチープカシオの話

## Episode Description

安いカシオの腕時計を一年以上愛用している。デジタル時計が苦手な理由から、回転ベゼル、ロッカーキー風のコイルバンド、サウナでの使い方まで、聞かれてもいないこだわりを話し始めた。
