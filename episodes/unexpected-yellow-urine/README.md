# 覚えのない黄色い尿。調べてみたら犯人は意外なところにいた

トイレで見つけた妙に鮮やかな黄色。ビタミン剤を飲んだ覚えはないのに、最近飲み始めた蕁麻疹の薬の成分を見たらB2が入っていた。そこから、薬に入っている補助成分と「隠れビタミン」を見ていく回です。
