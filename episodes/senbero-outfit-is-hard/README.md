# おっさんとセンベロ行く服が一番むずい

仕事のメンバーとセンベロ居酒屋へ行く時、何を着ていくかが妙に難しいところから始まる壁打ち回です。

気合いを入れすぎず、雑にもしたくない。そこから、オシャレに見られたいというより「ちゃんとしていたい」、人と会う時間を雑に扱いたくない、年齢を重ねても身だしなみの意識を手放したくないという話へ転がります。
