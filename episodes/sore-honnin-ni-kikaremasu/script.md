# アフタートーク「それ、本人に聞かれますよ？」

## 制作メモ

「ところで、この人何してるんですか？」収録直後のアフタートーク。

本編では、あまかわちゃん不在をいいことにAmakawachan Systemや壁ラジについて好き放題話したモブ子とモブ美。

ひたすらツッコミ続けて疲れ果てたモブ美に対して、モブ子は収録後ものほほんとした様子。

ようやく一息ついたところで、モブ子が本編最後の「絶対本人に聞かせるなよ」という発言について、Amakawachan Radioの重大な仕様を伝える。

本人不在回なのに、システム上は本人に筒抜け。

そして、その事実について話しているこのアフタートークも当然――。

本編より短い番外編として、二人のキャラクター性と関係性を掘り下げる。

## Character

### モブ美 / Host

- 本編でひたすらツッコミ続けて疲れている。
- 収録終了後なので完全に気が抜けている。
- 「本人がいないから言えた」という認識。
- あまかわちゃんとは付き合いが長いため本人の性格はよく知っているが、Amakawachan Systemの内部仕様にはまだ詳しくない。
- モブ子の天然発言によって徐々に精神を削られていく。
- 本編よりツッコミの勢いは弱め。疲労によって後半ほど反応が鈍くなる。

### モブ子 / Guest

- 本編終了後も特に疲れていない。
- モブ美がなぜそこまで疲れているのか、いまひとつ理解していない。
- モブ美を労っているつもりではある。
- Amakawachan Systemの仕様を当然のこととして理解している。
- 悪気なく重大な事実を後出しする。
- 本人に追い打ちをかけている自覚はない。
- 「聞かれたので答えました」くらいの感覚。
