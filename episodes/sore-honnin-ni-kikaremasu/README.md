# アフタートーク「それ、本人に聞かれますよ？」

「ところで、この人何してるんですか？」収録直後のアフタートーク。

本編でひたすらツッコミ続けて疲れ果てたモブ美に対して、モブ子は収録後ものほほんとした様子。

ようやく一息ついたところで、モブ子が本編最後の「絶対本人に聞かせるなよ」という発言について、Amakawachan Radioの重大な仕様を伝えます。

本人不在回なのに、システム上は本人に筒抜け。

そして、その事実について話しているこのアフタートークも当然――。

## Cast

- Host：モブ美
- Guest：モブ子
