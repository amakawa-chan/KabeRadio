# こうして深夜の壁打ちは終わらない

## Episode Description

モブ子とモブ美だけで収録した回の感想を聞いていただけでした。
気付けば公式アーカイブができて、台本の保存方法が変わって、公開用クレジットの自動生成まで話が進んでいました。
