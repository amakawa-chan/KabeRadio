# 電話が嫌いな私が、会社に休みの連絡をするためにトーストを焼く話

## Episode Description

会社に休みの連絡をするための電話が、どうしてもかけられない。人見知りと接客モード、人間関係を維持するコストから、自分の作ったものを見つけてほしい気持ちまで話が広がり、最後は食パンが登場する。
