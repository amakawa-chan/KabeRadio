# ASMRを作ろうとしたら空間音響スタジオになりそうな件

ASMRっぽい左右定位や耳元表現を試そうとしたところ、壁ラジの朗読・寸劇・キャラクター入退室にも使える空間音響演出エディタの構想へ発展した回です。

- Host: `amakawachan-layered`
- Guest: `mobuko-v2`
- Guest途中交代: `mobumi`

[正式台本](script.md)

## 今回のポイント

- 発話ごとの位置・距離・移動プリセット
- AIでざっくり演出を付け、気になる2割だけ後から調整する方針
- 距離感をGainだけでなくEQとRoom成分でも表現する案
- 無言の聞き手が脳内で応答する `listener_response` 的な間
- ASMR専用ではなく、壁ラジの空間音響演出へ再利用する構想
- 既存TTSとFFmpeg中心の試験レンダラーから検証開始
