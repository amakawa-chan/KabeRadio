# 体調で変わる、シャワーの締め方

シャワー後にまた汗をかくのが嫌、という生活の小さな不満から始まった壁打ち回です。

水シャワーは冷やした方がいいのか、冷やしすぎると逆なのか。サウナでは夏と冬で締め方が違うという実感まで持ち出し、最後は「冷ます工程そのものは固定して、温度と時間だけ変える」という日常運用に着地します。

後半では、最近の壁ラジが実装・運用の話に寄りすぎていたことにも触れ、生活のしょうもない疑問をちゃんと転がす回として整理しています。
