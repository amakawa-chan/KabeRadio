# 体調で変わる、シャワーの締め方

## Episode Description

シャワーを浴びてさっぱりしたはずなのに、上がったあとでまた汗をかくのが嫌でした。
水シャワーは効くのか、冷やしすぎると逆なのか。サウナの夏冬まで持ち出して考え始めます。
