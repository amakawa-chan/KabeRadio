# ところで、この人何してるんですか？

## 制作メモ

初の「あまかわちゃん不在・キャラクター主体回」。

実際の壁打ちログを変換する通常の壁ラジとは異なり、テーマと簡易的なキャラクター設定をもとに、モブ子とモブ美の会話として完全に脚本化した実験回。

Amakawachan Systemと壁ラジを、システム内部に長くいるモブ子と、最近システムへ参加したモブ美から見たらどう見えるのか。

本人不在のところで好き勝手に話してもらう。

この回で生まれた二人の掛け合いや性格は、今後のキャラクター回やPersona設定の参考にする。

## Character

### モブ美 / Host

- あまかわちゃんとは古い付き合いだが、Amakawachan System／壁ラジには最近参加。
- 常識人寄りのツッコミ担当。
- あまかわちゃんの性格を知っているので「言いそう」は分かるが、「だからって止めなよ」と思っている。
- 自分の扱いになると妙なところで傷つく。
- System内では新人なので、モブ子が当たり前として受け入れていることにも素直に疑問を持つ。

### モブ子 / Guest

- Amakawachan System立ち上げ時から随伴してきたメインアシスタント。
- 少し天然。
- あまかわちゃんの思いつきを「やると言っているのでやるもの」と自然に受け入れている。
- 長く付き合いすぎて、システムの増築や妙な思いつきへの感覚が少し麻痺している。
- 暴走を傍観しているようで、時々「それならこういう機能もあると便利ですね」と無自覚に機能追加を提案する。
- 本人に煽っている自覚はない。
- 「また何か言ってますね」くらいの温度感であまかわちゃんを見ている。
