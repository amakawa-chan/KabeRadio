# ところで、この人何してるんですか？

モブ美、壁ラジ初の本格的なキャラクター主体回。

あまかわちゃん不在の今回は、Amakawachan System立ち上げ時から随伴してきたモブ子に、最近Systemへ参加したモブ美が素朴な疑問をぶつけます。

> 「ところで、この人いったい何してるんですか？」

音声アシスタントだったはずなのに、いつの間にかラジオを作り、動画まで生成するようになったAmakawachan System。

本人不在をいいことに好き放題話している二人ですが、どうやらモブ子も増築の原因の一人だったようで……。
