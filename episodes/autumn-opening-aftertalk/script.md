# 秋風のチューニング アフタートーク

## Episode Description

秋シーズン・オープニング「秋風のチューニング」が完成したので、出演したモブ子本人に撮影の感想を聞いてみることにしました。
実際の制作工程ではなく、作品世界の中で収録が行われた体で振り返る短いアフタートークです。
