# EPISODES

壁ラジのエピソード一覧。

現在、公開用アーカイブは準備中です。

今後は各エピソードごとに概要、出演キャラクター、台本、制作メモなどを配置する予定です。

固定台本のない実行実験は、エピソードとして登録する前に [壁ラジ1](../docs/wall-radio1.md) のように記録します。実験runから公開用の台本を選んだ時点で、通常のエピソードページへ整形して追加します。

## Planned structure

```text
episodes/
├─ ep00/
│  ├─ README.md
│  └─ script.md
├─ ep01/
│  ├─ README.md
│  └─ script.md
└─ ...
```

キャラクター主体回やアフタートークも、通常回と区別できる形でここへ記録します。
