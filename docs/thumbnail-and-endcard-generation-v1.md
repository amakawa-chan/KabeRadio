# 壁ラジのサムネイル・エンドカード生成ルール

1本の台本から、YouTube用の文字ありサムネイルと、動画末尾用の文字なしエンドカードを作る。普段は既存のアイキャッチをサムネイルに使える。専用画像は、象徴的な小物や二人の反応などで、その回の話を一枚で伝えられるときに作る。

## 1. 対象回と場面を決める

- 回番号・動画URL・正式タイトルを照合し、`episodes/<episode-key>/script.md` の本文とCASTを見る。番外編や番号のない回は動画IDから特定する。台本が見つからず公開説明で制作した場合は、その根拠を成果物の報告に残す。
- 会話の転換点、最後に残る問い、対照的なリアクションのいずれかから、絵になる一瞬を選ぶ。画面中央の小物は一つを主役にする。話者、聞き手、各自がどこを見て何をしているかを具体的に決める。
- 既存のアイキャッチを使っている回も、依頼に含まれていれば台本別の新規絵を作る。公開中の画像の確認と、差し替えの依頼は別の操作として扱う。

## 2. キャラクター参照と演技

Radioで採用されているキャラクターパックの**顔まで合成済みの通常立ち絵**を用意する。レイヤーパックでは一般に `runtime/normal.png` が該当する。配置されたパックの実体は環境や版によって変わるので、現在のキャラクター登録から特定する。顔パーツが抜けた合成前の `base.png` では特徴を判断しづらい。

| キャラクター | 参照画像から維持する特徴 |
|---|---|
| あまかわちゃん（`amakawachan-layered`） | 深緑のボブ、長めの前髪、細い丸メガネ、黒いピアス、小さな牙、黒い襟付きシャツ |
| モブ子（`mobuko-v2` 系統） | プラチナブロンドのウェーブ、緑の瞳、白いフリルのヘッドドレスと黒白の衣装 |
| モブ美（`mobumi` 系統） | 赤みのあるウェーブボブ、灰色の瞳、そばかす、生成りのトップス |

- 参照は顔立ち・色・髪型・装身具・衣装のために使う。立ち絵の正面向き、目線、口の形、表情を引き継ぐようには指定しない。
- 各キャラに**別々の頭と肩の向き、視線の先、眉と口の動き、手の動き**を指定する。例として「あまかわちゃんは画面右向きの横顔で口を開いて質問し、モブ子は左斜め向きでカップ越しに片眉を上げる」。同じ小物を見ていても、視線の高さや反応に差をつける。
- 二人を正面向きに並べた構図を連発しない。手元寄り、机越しの低い視点、俯瞰、横顔、肩越しなどから、回の動作がいちばん伝わる画角を選ぶ。続けて複数回を作るときは、隣の回と画角・仕草・支配色を見比べる。

## 3. 画風と文字

- ベースは、線のはっきりしたアニメ調のラジオ挿絵。キャラは表情が読み取れる大きさで描き、照明を暖色の主光と青緑・紺・紫などの影に分ける。色は回の題材に合わせる。たとえば蝶の回は森の緑と橙、監査回は赤茶と紙色、管制室は青緑に赤いランプ。
- 16:9で、顔・手・話の核になる小物を左側から中央に置く。右側の約3分の1を落ち着いた面として残し、文字あり版は見出し、文字なし版はYouTubeの終了画面要素を置けるようにする。文字が必要な回でも、右下には再生時間表示の余白を取る。
- 先に**文字なしの完成絵**を作り、確認した絵を元に文字だけ追加する。服や照明の色まで変わった場合は、元絵を指定して文字追加をやり直す。
- 見出しは原則2行の短い日本語。ボールドのゴシック体、濃い背景、白系＋黄を基本にし、強調語が入る行に黄色を使う。配色に合わせた変更は可。出演者名・固有名詞の表記は元台本や動画タイトルと照合する。疑問や想像として話している内容は、断定に変えない。

## 4. プロンプトのひな形

**文字なしの元絵**

```text
壁ラジ［対象回］の16:9の文字なしイラスト。
参照画像1は［人物A］、画像2は［人物B］の顔立ち・髪・衣装の参照。
参照画像の正面向きや表情を写さず、［台本の具体的な一場面］を描く。
人物Aは［画面上の位置・顔の向き・視線の先・表情・手の動き］。
人物Bは［Aと異なる向き・視線の先・表情・手の動き］。
［画角］から見て、［回を象徴する小物］が読める構図。
線が明瞭なアニメ調イラスト。［暖色の主光］と［影の色］。
顔と小物は左から中央。右の約3分の1は濃く静かな余白。
文字・ロゴ・透かしなし。小さく見ても人物の反応がわかる。
```

**文字あり版**

```text
添付した完成絵の右の余白に、次の2行だけを追加。
1行目「［正確な文字列］」を白系、2行目「［正確な文字列］」を黄色。
太い日本語ゴシック体、濃い縁、右端と右下に余白。
顔の向き・目線・表情・小物・配色・構図は元絵と同じ。
文字が人物や小物にかからないようにする。
```

## 5. 確認・書き出し

- 文字ありは 1920×1080 JPG、Radioに指定するサムネイルは2 MB以下。文字なしは 1920×1080 PNG。ローカル素材は `endcards/<episode-key>/thumbnail-v1.jpg` と `endcard-v1.png` のように組で保存し、改稿は版番号を増やす。
- 画像を320×180で表示し、見出しの全字、キャラの見分け、視線と表情の違い、話を象徴する小物が読み取れるかを確認する。文字なし版は終了画面を右に重ねても顔と小物が隠れないかを見る。視認性の確認と、公開後の視聴データによる比較は区別する。
- 生成と既存動画への反映は別の作業。動画に焼き込むエンドカードはレンダー時に指定し、YouTube Studioで設定するクリック可能な終了画面とは区別する。
