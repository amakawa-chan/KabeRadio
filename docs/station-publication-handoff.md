# 放送局への公開引き継ぎ

本編のレンダー、YouTube投稿、放送局への掲載はそれぞれ別の結果を持つ。
本編MP3が生成されても、放送局の紹介MP3がそろったことにはならない。

| 確認するもの | 正本・判定 |
|---|---|
| 字幕と読み上げ | 本編の台本対。読みの補正が必要な箇所は speech だけを直し、subtitle は正式表記を維持する。 |
| YouTube投稿 | 本編の投稿記録、動画ID、公開状態。話数・プレイリストも別に確認する。 |
| 放送局の話数 | YouTubeの「【壁ラジ】#番号」付き本編タイトルを優先。取得不能時は保存済みYouTubeタイトル、番号が得られない旧回はSpotifyの番号を補完に使う。番号なしの新規回に推測値を付けない。 |
| 放送局の紹介 | `site/intros/<episode-key>.mp3` が必要。索引の欠落警告を見て不足分だけ作る。本編を再レンダーする必要はない。 |

紹介音声の自動化は [#39](https://github.com/amakawa-chan/KabeRadio/issues/39) で扱う。表示用・読み上げ用番宣の契約と生成ツールは [#40](https://github.com/amakawa-chan/KabeRadio/pull/40)・[#41](https://github.com/amakawa-chan/KabeRadio/pull/41) を先に揃え、本編の制作ジョブから紹介MP3の生成へつなぐ。生成に失敗した場合は紹介だけを再試行できるようにし、完成済み本編のレンダーや投稿を繰り返さない。
