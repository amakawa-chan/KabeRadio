# あまかわちゃん — 秋のnoteプロフィール素材

壁ラジの秋の世界観に合わせた、あまかわちゃんのアイコンとヘッダーです。
黒緑のボブ、丸眼鏡、ピアス、ちらっと見える牙を残し、暖かなカフェの光と紅葉を合わせました。
