## 制作について

- 秋MVとNG集の画像をリファレンスに、AIによる画像生成で制作しました。
- アイコンはNG集の泡ひげモブ子をもとに、正方形の構図にしています。
- 設定用PNGは生成原本からリサイズしたものです。原本も編集用アセットとして保存しています。
