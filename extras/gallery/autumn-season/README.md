## 保存画像について

- `mv/`：MV本編に使用したイラストのPNG。動画からの切り出しではなく、編集前の画像素材です。
- `ng/`：本編の場面をリファレンスに追加制作したNGイラストのPNG。
- 画像制作にはAIによる生成・編集を使用しています。
