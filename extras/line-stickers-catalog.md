# LINEスタンプ台帳

壁ラジ / Amakawachan System 関連のLINEスタンプを、今後の重複確認・新弾企画・制作記録のためにまとめる台帳です。

販売案内は `extras/line-stickers.md` を正とし、このファイルでは各セットの内容・出典・確認状況を管理します。

## 管理方針

- 実際の申請・販売データやmanifestが存在する場合は、その内容を正本として記録する。
- 販売ページや台本からしか確認できない情報は「確認済み範囲」として明記する。
- 復元できていない文言を推測で埋めない。
- 新しいスタンプ案を作る際は、この台帳と照合して既存文言・用途の重複を確認する。
- 新弾は可能なら専用manifestを作り、`id / text / category / usage / characters / source / status` を残す。

## 次弾候補: 壁ラジPOP（仮）

### コンセプト

既存の壁ラジVol.1 / Vol.2が比較的ニッチ・番組寄りであることを踏まえ、次弾は日常で使いやすい汎用文言を中心にする。

新しく壁ラジ用に作ったPOP系素材を活かし、1人・2人・3人構図を混在させて「文言は汎用、見た目は壁ラジ」を狙う。

### 想定仕様

- 最大40枚
- 1人 / 2人 / 3人構図を混在
- 汎用比率を高める
- 既存モブ子Vol.1の強い固有文言との重複はなるべく避ける
- 壁ラジ固有ネタはアクセント程度に残す
- 3人構図は集合感・番組感・締め用途を中心にする

### 既存モブ子Vol.1と特に重複注意

以下は既存セットにあるため、同一文言を使う場合は「壁ラジPOPとして別構図にする明確な理由」が必要。
